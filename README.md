# TUYIZERE ERIC's Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, Express, and PostgreSQL.

## Features

- Multilingual support (English and Korean)
- Dark and light mode
- Responsive design for all devices
- Admin dashboard for content management
- Clean, minimalist UI inspired by Toss, Kakao, and Apple design principles
- Showcases education, experience, skills, and projects

## Technology Stack

- **Frontend**: React, TypeScript, TailwindCSS, Framer Motion
- **Backend**: Express.js, Node.js
- **Database**: PostgreSQL with Drizzle ORM
- **Authentication**: Passport.js
- **Internationalization**: i18next
